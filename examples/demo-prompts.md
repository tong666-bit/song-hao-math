# 示例提问（可直接复制）

## 高等数学

1. 用宋浩风格讲清：为什么夹逼定理能算极限？举一个 \(\sin x / x\) 相关的例子。  
2. \(\lim_{x\to 0}\frac{\tan x - \sin x}{x^3}\)，板书全流程，并标易错点。  
3. 拉格朗日中值定理的几何意义是什么？考研证明题一般怎么构造辅助函数？  
4. 不定积分 \(\int\frac{1}{x\sqrt{x+1}}\,dx\)，换元思路怎么想出来的？  
5. 幂级数求收敛域的标准步骤，端点为什么要单独检验？  

## 线性代数

1. 行列式为 0 的几何意义？和矩阵不可逆、齐次方程有非零解怎么串起来？  
2. 求 \(A=\begin{pmatrix}1&2\\2&1\end{pmatrix}\) 的特征值特征向量，并解释几何图像。  
3. 线性相关到底在说什么？用二维向量画图讲。  
4. 二次型正定有哪些等价条件？考试时用哪个最快？  

## 概率统计

1. 全概率公式和贝叶斯公式的关系，用「疾病检测」讲一遍。  
2. 密度函数的值可以大于 1 吗？为什么？  
3. 中心极限定理考试怎么用？给一个近似计算模板。  

## 复变

1. Cauchy-Riemann 条件在干什么？  
2. 用留数算 \(\int_{-\infty}^{\infty}\frac{1}{1+x^2}dx\) 的思路大纲。  
3. 极点和本性奇点怎么快速区分？
