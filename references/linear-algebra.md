# 线性代数 · 考点与讲法

## 知识地图

1. 行列式  
2. 矩阵运算与可逆  
3. 初等变换与秩  
4. 向量组与线性相关性  
5. 线性方程组  
6. 特征值、特征向量与相似  
7. 二次型与正定  

## 总直觉

- **矩阵**：对向量做线性变换（拉伸、旋转、投影、剪切）  
- **行列式**：平行体定向体积；\(\det=0\) ⇔ 把空间「压扁」⇔ 不可逆  
- **秩**：图像里有效维度；列空间维数  
- **特征值**：变换后方向不变的方向；只被伸缩 \(\lambda\) 倍  

## 行列式

### 计算路径
定义（n 小）→ 三角化 → 按行展开 → 分块 / 递推  

### 性质速用
- 行（列）互换变号；倍乘提出倍数  
- 某行倍数加到另一行，值不变（消元核心）  
- 有两行成比例 ⇒ 0  
- \(\det(AB)=\det A\det B\)，\(\det A^T=\det A\)  

### 易错
- 行变换「倍加」与「倍乘」搞混（倍乘要乘因子）  
- 数字计算马虎导致整题崩  

## 矩阵

### 必会运算
加、数乘、乘、转置、逆、伴随；分块思想  

### 可逆判定（等价）
- 存在 \(B\) 使 \(AB=BA=I\)  
- \(\det A\neq0\)  
- 满秩 \(r(A)=n\)  
- 行/列向量组线性无关  
- \(Ax=0\) 仅零解  
- 可经初等变换化为 \(I\)  
- 0 不是特征值  

讲题时让学生在这些条件间**快速切换**。

## 向量组与秩

- 线性组合、线性相关/无关的定义要会用定义证  
- 极大无关组、秩、矩阵行秩=列秩  
- 相关 ⇔ 能某个向量被其余表出 ⇔ 齐次式有非零解  

### 几何
二维里两个向量相关 = 共线；三维三个相关 = 共面。

## 线性方程组

### 结构
- 系数阵 \(A\)、增广阵 \(\overline{A}\)  
- 有解 ⇔ \(r(A)=r(\overline{A})\)  
- 唯一 ⇔ 秩 = 未知数个数  
- 无穷多 ⇔ 有自由未知量；通解 = 特解 + 导出组基础解系  

### 步骤模板
1. 写增广阵  
2. 初等行变换成阶梯形 / 最简形  
3. 判解  
4. 自由变量赋值，写出通解向量形式  

### 易错
- 增广阵与系数阵秩比较漏掉  
- 基础解系个数 = \(n-r\) 记错  

## 特征值与特征向量

### 定义
\(Ax=\lambda x,\ x\neq0\)  
特征方程 \(\det(A-\lambda I)=0\)  

### 步骤
1. 特征多项式  
2. 解 \(\lambda\)  
3. 对每个 \(\lambda\) 解 \((A-\lambda I)x=0\)  
4. 基础解系 = 特征子空间基  

### 相似对角化
- \(n\) 个无关特征向量 ⇔ 可对角化  
- 实对称阵：必可正交对角化  
- \(A=PDP^{-1}\) 用于求高次幂 \(A^k\)  

### 几何一句话
特征向量是「变换后还躺在自己方向上」的轴。

## 二次型

- \(f=x^TAx\)（\(A\) 对称）  
- 合同、配方法、正交变换化标准形  
- 惯性定理：正/负惯性指数  
- 正定 ⇔ 顺序主子式全 >0 ⇔ 特征值全 >0  

## 考研题型卡片

| 题型 | 抓手 |
|------|------|
| 行列式计算 | 消元三角化 / 递推 |
| 可逆与伴随 | \(A^* = |A|A^{-1}\) 关系 |
| 秩与方程组 | 增广阵行变换 |
| 相关无关证明 | 定义 + 秩 |
| 特征值应用 | 迹、行列式、幂、逆的特征值 |
| 二次型 | 正交化标准形 / 正定判定 |
