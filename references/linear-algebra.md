# 线性代数 · 考点与讲法

## 知识地图

1. 行列式
2. 矩阵运算与可逆
3. 初等变换与秩
4. 向量组与线性相关性
5. 线性方程组
6. 特征值、特征向量与相似
7. 二次型与正定

## 总直觉

- **矩阵**：对向量做线性变换（拉伸、旋转、投影、剪切）
- **行列式**：平行体定向体积；\(\det=0\) ⇔ 把空间「压扁」⇔ 不可逆
- **秩**：图像里有效维度；列空间维数
- **特征值**：变换后方向不变的方向；只被伸缩 \(\lambda\) 倍

## 行列式

### 计算路径
定义（n 小）→ 三角化 → 按行展开 → 分块 / 递推

### 性质速用
- 行（列）互换变号；倍乘提出倍数
- 某行倍数加到另一行，值不变（消元核心）
- 有两行成比例 ⇒ 0
- \(\det(AB)=\det A\det B\)，\(\det A^T=\det A\)

### 易错
- 行变换「倍加」与「倍乘」搞混（倍乘要乘因子）
- 数字计算马虎导致整题崩

## 矩阵

### 必会运算
加、数乘、乘、转置、逆、伴随；分块思想

### 可逆判定（等价）
- 存在 \(B\) 使 \(AB=BA=I\)
- \(\det A\neq0\)
- 满秩 \(r(A)=n\)
- 行/列向量组线性无关
- \(Ax=0\) 仅零解
- 可经初等变换化为 \(I\)
- 0 不是特征值

讲题时让学生在这些条件间**快速切换**。

## 向量组与秩

- 线性组合、线性相关/无关的定义要会用定义证
- 极大无关组、秩、矩阵行秩=列秩
- 相关 ⇔ 能某个向量被其余表出 ⇔ 齐次式有非零解

### 几何
二维里两个向量相关 = 共线；三维三个相关 = 共面。

## 线性方程组

### 结构
- 系数阵 \(A\)、增广阵 \(\overline{A}\)
- 有解 ⇔ \(r(A)=r(\overline{A})\)
- 唯一解 ⇔ 有解且系数矩阵秩等于未知数个数
- 无穷多 ⇔ 有自由未知量；通解 = 特解 + 导出组基础解系

### 步骤模板
1. 写增广阵
2. 初等行变换成阶梯形 / 最简形
3. 判解
4. 自由变量赋值，写出通解向量形式

### 易错
- 增广阵与系数阵秩比较漏掉
- 基础解系个数 = \(n-r\) 记错

## 特征值与特征向量

### 定义
\(Ax=\lambda x,\ x\neq0\)
特征方程 \(\det(A-\lambda I)=0\)

### 步骤
1. 特征多项式
2. 解 \(\lambda\)
3. 对每个 \(\lambda\) 解 \((A-\lambda I)x=0\)
4. 基础解系 = 特征子空间基

### 相似对角化
- \(n\) 个无关特征向量 ⇔ 可对角化
- 实对称阵：必可正交对角化
- \(A=PDP^{-1}\) 用于求高次幂 \(A^k\)

### 几何一句话
特征向量是「变换后还躺在自己方向上」的轴。

## 二次型

- \(f=x^TAx\)（\(A\) 对称）
- 合同、配方法、正交变换化标准形
- 惯性定理：正/负惯性指数
- 正定 ⇔ 顺序主子式全 >0 ⇔ 特征值全 >0

## 考研题型卡片

| 题型 | 抓手 |
|------|------|
| 行列式计算 | 消元三角化 / 递推 |
| 可逆与伴随 | \(A^* = |A|A^{-1}\) 关系 |

## 条件、空间与参数（补充）

具体例题见[worked-examples.md](worked-examples.md)，公开课程见[sources.md](sources.md)。

可逆/行列式/特征值等价判定默认A为n×n方阵；矩形阵应说满行秩或满列秩，不能称通常意义的可逆。

### 四个子空间

对m×n矩阵A、秩r：
列空间维数r；零空间维数n-r；
行空间维数r；Aᵀ的零空间维数m-r。
Ax=b有解当且仅当b在列空间中。行变换保留零空间的方程解关系，不必保留原矩阵列空间本身；求原列空间基时用原矩阵对应主元列。

### 参数与方程组

先列可能使主元为零的参数，再分支消元。不能除以未排除为零的参数。唯一解需**有解且秩等于未知数个数**；秩小于未知数个数并不能排除无解。

通解是一个特解加齐次解空间。基础解系描述齐次方程，不把非齐次特解计入其基的个数。

### 谱与二次型

固定在R或C中讨论。对角化需要该数域中有n个无关特征向量；各特征值的几何重数等于代数重数是等价判据。不同特征值对应特征向量无关，重特征值不能只数根数。

相似P⁻¹AP与合同PᵀAP服务不同任务。实对称正定的Sylvester判据是所有顺序主子式>0；半正定不能只用“顺序主子式≥0”替代完整判据。

伴随矩阵恒满足AA*=A*A=det(A)I；只有A可逆时才写A*=det(A)A⁻¹。

### 复核

特征向量代回Av=λv，并确认v非零；方程解代回Ax=b；正交对角化检查QᵀQ=I及QᵀAQ；矩阵幂先用k=0,1做边界复核。
