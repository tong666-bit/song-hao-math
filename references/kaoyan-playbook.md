# 考研数学：范围筛选、题型选择与复盘

## 科目差异（备考方向，不替代当年大纲）

| 模块 | 数一 | 数二 | 数三 |
|---|---|---|---|
| 微积分/高数 | 有 | 有 | 有，应用背景可能不同 |
| 线性代数 | 有 | 有 | 有 |
| 概率统计 | 有 | 通常无 | 有 |
| 曲线曲面积分、级数等细项 | 按当年大纲 | 按当年大纲，不能把数一清单直接复制 | 按当年大纲 |
| 复变函数 | 通常独立本科/专业课 | 同左 | 同左 |

数二不是“只计算不证明”，数一中向量微积分不等于复变函数。旧版“多元较少”等描述过于模糊，规划需列具体章节对照。公开官方入口与版本限制见[sources.md](sources.md)；本次未取得2027学科大纲全文，不给未核验的当年分值比例。

## 选方法前写一句理由

| 题型 | 先问什么 | 常用抓手 |
|---|---|---|
| 极限 | 类型？主部是否抵消？左右是否一致？ | 等价、展开、夹逼、洛必达 |
| 积分 | 区间/瑕点？结构/对称？ | 换元、分部、对称 |
| 证明 | 定理条件和要证明的量？ | 定义、辅助函数、中值 |
| 方程组 | 参数会让主元为0吗？ | 增广矩阵、分类讨论 |
| 谱/二次型 | 数域？特征空间维数？相似还是合同？ | 谱分解、惯性、正定 |
| 概率 | 条件事件？支持域？独立假设？ | 全概率、Bayes、CDF |
| 统计 | 样本分布？参数已知？ | 枢轴量、拒绝域 |

不要为背套路忽略题面。完整演示见[worked-examples.md](worked-examples.md)。

## 过程表达与时间

先列已知、方法和关键关系，再计算。不会后半问时可以交付已完成的有效部分，但不承诺任意抄公式就有固定步骤分。题干未给评分标准时，只指出可能的关键得分环节。

模考按当次科目总时长制定预算，保留检查、涂卡和参数/端点复核。卡住时先完成可做题，复盘再补概念；不机械规定所有学生同一解题顺序。

## 复盘闭环

概念卡点 → 最小例子 → 独立同型题 → 只改一个条件的变式 → 混合题识别。
错误按条件、计算、方法、表达分类，定位第一处不成立步骤，参见[error-diagnosis.md](error-diagnosis.md)。

短期复习优先修复反复出现的错误，不以“每天看完多少节课”衡量掌握。时间预算与调整见[study-plans.md](study-plans.md)。
