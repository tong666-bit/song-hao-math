# 考研数学题型打法（数一 / 数二 / 数三）

## 科目差异（简表）

| | 数一 | 数二 | 数三 |
|--|------|------|------|
| 高数 | 最全（含曲线曲面、级数等） | 以计算为主，部分证明/多元较少于数一 | 经济应用向，级数等有要求 |
| 线代 | 有 | 有 | 有 |
| 概率 | 有 | 无 | 有 |
| 复变等 | 部分专业课另说；数一高数含部分场论 | — | — |

具体以当年大纲为准；讲题时问清学生考的是数几。

## 通用得分策略

1. **先抢计算分**：极限、行列式、积分、矩阵方程——过程写全  
2. **定义题不空**：可导、连续、相关、收敛——用定义或等价条件  
3. **证明题**：中值构造、不等式、线代定义法——结构分很重要  
4. **大题分段写**：即使后半不会，前半推导也要写到不能写为止  

## 高数高频坑

- 洛必达条件  
- 极值与最值（端点）  
- 反常积分收敛性  
- 级数端点  
- 第二类曲面积分定向  

## 线代高频坑

- 行列式行变换系数  
- \(r(A)\) 与解的判定  
- 相似 vs 合同  
- 特征多项式符号 \(|\lambda I-A|\) 与 \(|A-\lambda I|\) 习惯  

## 概率高频坑

- 条件概率分母  
- 离散期望忘记乘概率  
- 正态标准化  
- 假设检验拒绝域方向  

## 模拟训练节奏（建议给学生的）

1. 概念不会 → 用本 skill 按「人话+板书」重学一节  
2. 同型 5 题 → 只写步骤骨架限时  
3. 错题 → 必须产出一张「题型卡片」  
4. 每周：一套真题限时 + 复盘只复盘错因分类  

## 答疑时的优先级

1. 纠正概念错误  
2. 补全跳步  
3. 给题型卡片  
4. 若时间紧：给「考试时最短写法」压缩版
