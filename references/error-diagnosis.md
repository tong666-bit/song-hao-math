# 错因诊断与最小反例

批改先定位**第一处不成立的推理**，保留此前正确步骤，再给最小修改与一题同型迁移。数值核对是辅助，不代替证明。

| 易错命题 | 最小检查/反例 | 纠正动作 |
|---|---|---|
| 连续就可导 | f(x)=|x|在0连续，左右导数-1、1 | 分别用定义算左右 |
| 可导就导函数连续 | x²sin(1/x)，0处补0，可导但导数在0不连续 | 区分原函数和导函数性质 |
| 等价无穷小可任意相减 | tan x-sin x 的一阶主部抵消 | 展开到首个非零项 |
| 导数比极限不存在，原比也不存在 | (x+sin x)/x→1，导数比1+cos x无极限 | 洛必达是充分工具，失败不等于原极限失败 |
| 各偏导存在就连续/可微 | xy/(x²+y²)，原点补0，沿轴0、沿y=x为1/2 | 多路径与线性余项 |
| 通项趋0就级数收敛 | ∑1/n发散 | 必要条件之后再用判别法 |
| 特征值重复就不能对角化 | I₂可对角化 | 查特征空间维数 |
| det相同就相似 | diag(1,4)和diag(2,2)行列式都4，迹不同 | 查谱/迹等必要条件 |
| 相似就是合同 | 形式分别P⁻¹AP和PᵀAP | 对齐线性变换/二次型任务 |
| 不相关就是独立 | X均匀(-1,1)，Y=X² | 检查联合与边缘 |
| 边缘正态+不相关就独立 | 缺联合正态条件 | 不偷换“联合正态” |
| CR在一点成立就邻域解析 | z↦|z|²在0满足CR且在0复可导，但不在其邻域解析 | 分清点可导和开域解析 |
| 解析就闭积分0 | 1/z绕原点，积分2πi | 查区域/奇点/围道 |
| 概率密度≤1 | U(0,1/2)密度2 | 看面积而非高度 |

以上均为自编复核示例。反例中的点、区间和补定义不可遗漏。

## 方法选择卡

极限：先认型、检查抵消与左右，再选等价/展开/夹逼/洛必达。
积分：先看定义域与收敛，随后选换元/分部/对称。
线代：参数先分类；数值结果代回Av=λv或Ax=b。
概率：先写事件与样本空间，再列条件式与支持域。
复变：画出奇点和路径，检查路径上有无奇点，再用积分公式/留数。

一题结束后的迁移只改变一个关键条件，迫使学生重新判断方法适用性。
