1. 函数与极限 → 连续

## 极限

### 核心直觉
\(x\to a\) 时，\(f(x)\) 无限贴近某个数 \(L\)，与 \(f(a)\) 是否有定义无关。

### 常用工具箱
- 四则运算、夹逼、单调有界  
- 等价无穷小（\(x\to0\)）：  
  \(\sin x\sim x,\ \tan x\sim x,\ 1-\cos x\sim x^2/2,\ \ln(1+x)\sim x,\ e^x-1\sim x,\ (1+x)^a-1\sim ax\)  
- 两个重要极限  
- Taylor / 展开比等价更强  
- 洛必达：仅 \(\frac{0}{0},\frac{\infty}{\infty}\)，且条件满足时才能用  

### 题型步骤（未定式）
1. 认出型（0/0, ∞/∞, 0·∞, ∞-∞, 1^∞, 0^0, ∞^0）  
2. 化到 0/0 或 ∞/∞（取对数、通分、有理化）  
3. 等价替换（乘除易用，加减慎用）或洛必达或展开  
4. 回代，写极限值  

### 易错
- 等价用于加减导致主部消掉  
- 洛必达后极限不存在就断言原极限不存在（不成立）  
- 忽略 \(x\to\infty\) 与 \(x\to0\) 等价式不同  

## 导数与中值定理

### 直觉
导数 = 瞬时变化率 = 切线斜率。

### 必须会
- 定义式 \(f'(x_0)=\lim_{h\to0}\frac{f(x_0+h)-f(x_0)}{h}\)  
- 四则、复合、反函数、参数方程、隐函数  
- 高阶导、 Leibniz  

### 中值定理族
- Rolle → Lagrange → Cauchy  
- 几何：割线平行于某点切线  
- 证明题：构造辅助函数是常规操作  

### Taylor
- 带 Peano / Lagrange 余项  
- 考研：用展开算极限、近似、不等式  

## 积分

### 直觉
定积分 = 有向面积 / 总量；微积分基本定理把「求导」与「积分」接起来。

### 技术清单
- 换元、分部、有理函数、三角有理、倒代换  
- 定积分：对称性、区间可加、变限积分求导  
- 反常积分：无穷限 / 瑕点；比较判别、极限判别  

### 易错
- 换元忘改限  
- 绝对值分段  
- 变限积分：上下限都是函数时用链式法则  

## 微分方程

| 类型 | 识别 | 思路 |
|------|------|------|
| 可分离 | \(y'=f(x)g(y)\) | 分离两端积分 |
| 齐次 | \(y'=f(y/x)\) | \(u=y/x\) |
| 一阶线性 | \(y'+P y=Q\) | 积分因子 \(e^{\int P}\) |
| 二阶常系齐次 | 特征方程 | 根的类型定通解 |
| 非齐次 | 右端形式 | 待定特解 + 通解 |

先判断类型，再套模板；初值问题最后定常数。

## 多元与重积分（提要）

- 偏导：一次只动一个变量  
- 全微分：线性主部  
- 极值：临界点 + Hessian；条件极值：Lagrange 乘子  
- 重积分：选坐标系（直角 / 极 / 柱 / 球）由区域与被积函数对称性决定  
- 曲线曲面积分：Green / Stokes / Gauss 的条件与定向  

## 级数

- 数项：必要、比较、比值、根值、积分、交错 Leibniz、绝对 vs 条件收敛  
- 幂级数：收敛半径与区间、和函数、逐项导积  
- 把函数展开成幂级数：已知展开 + 运算  

## 考研高频「一句话」

- 极限：主部思想  
- 导数定义：求没见过的导数或讨论可导  
- 积分：对称与分段  
- 中值：构造函数  
- 级数：先半径后端点
