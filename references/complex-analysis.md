# 复变函数 · 考点与讲法

## 知识地图

1. 复数与复平面、极式与 De Moivre  
2. 复变函数、极限与连续  
3. 解析函数、Cauchy-Riemann、初等解析函数  
4. 复积分、Cauchy 定理与积分公式  
5. 级数：Taylor / Laurent  
6. 孤立奇点分类、留数、留数定理  
7. （可选）辐角原理、保角映射入门  

## 总直觉

- 复数 = 平面点 / 向量；乘一个复数 = **旋转 + 伸缩**  
- **解析** ≈ 在区域上可导且导数表现良好（CR 条件 + 开集）  
- 复积分有「路径」；解析时往往**与路径无关**（同伦/单连通条件下）  
- **留数** = Laurent 展开里 \(1/(z-z_0)\) 的系数；闭曲线积分 = \(2\pi i\times\) 内留数和  

## 复数基础

- 代数式 \(a+bi\)、共轭、模、辐角主值  
- 欧拉：\(e^{i\theta}=\cos\theta+i\sin\theta\)  
- 开方、多项式根在复平面的对称性  

## 解析与 CR

### Cauchy-Riemann
\(f=u+iv\) 解析 ⇒ \(u_x=v_y,\ u_y=-v_x\)（在可微前提下）  
充分条件：偏导连续且满足 CR。

### 讲法
「各个方向的导数要一致」——只沿实轴、虚轴算一样还不够严谨，但 CR 就是在管这个一致性。

### 常见解析函数
多项式、有理（极点除外）、指数三角双曲、支割后的对数与根式。

## 复积分

- 定义：对参数路径的积分  
- 估计不等式：\(|\int_C f|\le ML\)  
- Cauchy 定理：解析 + 单连通，闭积分 0  
- Cauchy 积分公式：  
  \[
  f^{(n)}(z_0)=\frac{n!}{2\pi i}\int_C\frac{f(z)}{(z-z_0)^{n+1}}dz
  \]  
  **识别**：分子解析，分母是 \((z-z_0)^{k}\)，直接套公式  

## Laurent 与奇点

| 奇点类型 | Laurent 主部 | 识别 |
|----------|--------------|------|
| 可去 | 无负幂 | 极限存在有限 |
| 极点 \(m\) 阶 | 有限负幂到 \(-m\) | \((z-z_0)^m f\) 解析非零 |
| 本性 | 无限多负幂 | 如 \(e^{1/z}\) 在 0 |

## 留数计算

1. **简单极点**：\(\operatorname{Res}=\lim_{z\to z_0}(z-z_0)f(z)\)  
2. **\(m\) 阶极点**：  
   \(\frac{1}{(m-1)!}\lim_{z\to z_0}\frac{d^{m-1}}{dz^{m-1}}[(z-z_0)^m f(z)]\)  
3. **已知展开**：直接读 \( (z-z_0)^{-1} \) 系数  
4. **无穷远留数**（若课程需要）：与有限平面留数关系  

## 留数定理应用

- 闭曲线正定向，内部解析点不贡献，奇点贡献 \(2\pi i\sum\mathrm{Res}\)  
- 实积分转化：有理三角积分、有理函数在实轴上的积分（上半平面闭包）  
- **讲清**：为什么补半圆、弧上积分为何趋于 0  

## 易错

- 支点与割支：对数主值跳跃  
- 定向：逆时针为正  
- 奇点是否在围道**内部**  
- 阶数判断错误导致留数公式用错
